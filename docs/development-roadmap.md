## 17. Technical risks

| Risk                                  | Mitigation                                                                                                                                                                                   |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Scope is very large (17 modules)      | Strict phases; each module goes through implement → test → document before the next; PROGRESS.md                                                                                             |
| Mongo transactions need a replica set | Single-node RS in development, 3-node in production, RS mode in the test harness                                                                                                             |
| Assignment race conditions            | Redis pool lock + optimistic `assignmentVersion` + idempotent plan jobs + concurrency tests                                                                                                  |
| Analytics slow on large data          | Indexes, `dailySnapshots` pre-aggregation, TanStack Query caching, Redis cache for dashboard (60 s)                                                                                          |
| Gantt has no good free library        | Custom timeline component, scoped to bars, dependencies and drag-resize                                                                                                                      |
| LLM data leakage / prompt injection   | Ask Your Data maps to a whitelisted intent schema only; scoped results; no raw DB access; PII-minimised prompts; AI outputs are proposals that need confirmation; admin toggle to disable AI |
| On-prem ops burden                    | One-command Compose deploy, backup scripts, health endpoints, runbook                                                                                                                        |
| Employee monitoring sensitivity       | Work Passport and analytics are operational only: no automatic performance scoring, and visibility is limited to the manager chain                                                           |
